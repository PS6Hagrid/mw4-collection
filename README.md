# MW4 Collection

Deine MW4-Camos als Sammelalbum. Die App trägt selbst ein, was du freigeschaltet hast: Du öffnest im Spiel den Tarnungen-Bildschirm einer Waffe, und eine Sekunde später klebt der Sticker im Album.

Unter „Aufgaben“ siehst du, welche Spezial-Tarnungen dir noch fehlen, nach Sorte: etwa alle offenen Longshots auf einen Blick. Eine Zeile für euren Chat kopierst du mit einem Klick.

Ein Fan-Projekt unter Freunden, nicht von Activision und nicht mit Call of Duty verbunden.

## Installieren

1. [Neueste Version](https://github.com/PS6Hagrid/mw4-collection/releases/latest) öffnen. Unter **Assets** lädst du `MW4-Collection-Setup-….exe` herunter.
   - Warnt dein Browser, die Datei werde selten heruntergeladen, wähl **„Beibehalten“** (bei Edge über „…“). Das kommt davon, dass die App nicht signiert ist.
2. Doppelklicken. Windows warnt einmal, weil die App nicht signiert ist: **„Weitere Informationen“ → „Trotzdem ausführen“**.
3. Die App startet ab dann mit Windows. Beim ersten Start erklärt dir eine Karte das Wichtigste.
4. **MW4 auf „Vollbild (rahmenloses Fenster)“ stellen.** Sieht die App nur Schwarz, sagt sie dir das oben in der Leiste.

Geprüft im Format 16:9 mit dem Spiel auf Deutsch oder Englisch: 2560×1440 im Spiel, 1920×1080 und 3840×2160 mit umgerechneten Aufnahmen. Ultrawide (21:9) und 16:10 sind noch nicht geprüft. Hast du so einen Bildschirm, drück im Spiel auf dem Tarnungen-Bildschirm `Strg+Umschalt+P` und schick den Ordner vom Desktop.

## Was die App tut, und was nie

- Sie liest nur den Bildschirm, wie OBS oder Medal, mit der Texterkennung von Windows auf deinem PC. Ins Spiel greift sie nie ein.
- **Auf eigenes Risiko.** Activisions Regeln erlauben keine fremde Software, die mit dem Spiel zusammenarbeitet oder Informationen daraus liest. Das trifft auch diese App, so wie streng genommen OBS oder Discord. Activision geht nach allem, was bekannt ist, gegen Cheats vor: Programme, die ins Spiel eingreifen, seinen Speicher lesen oder Eingaben fälschen. Nichts davon tut die App, eine Garantie gegen eine Sperre ist das aber nicht. Am vorsichtigsten bist du mit ausgeschaltetem Overlay: Rechtsklick auf das Symbol im Infobereich → „Overlay im Spiel“.
- Dein Fortschritt bleibt auf deinem PC (`%APPDATA%\MW4 Collection`).
- Ins Internet geht nur die Update-Prüfung: Sie fragt hier bei GitHub nach einer neuen Version.

## Updates

- Neue Versionen lädt die App still im Hintergrund.
- Installiert wird nie mitten im Spiel. Das passiert, wenn du oben auf **Update** klickst; die App startet dann kurz neu.
- Oder du beendest die App: unten rechts im Infobereich Rechtsklick auf ihr Symbol → **Beenden**. Beim nächsten Start ist sie dann neu. Das X am Fenster legt sie nur in den Infobereich.

## Wenn etwas nicht klappt

Drück im Spiel **Strg+Umschalt+P**. Auf dem Desktop liegt dann ein Ordner „MW4 Collection Problem …“. Schick ihn an die Person, von der du den Link hast. Die App selbst verschickt nichts.
